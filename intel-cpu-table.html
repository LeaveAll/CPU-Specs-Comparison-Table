How to use this table

Vendor buttons (Intel / AMD)

Toggle which vendor's CPUs are listed. Both on shows everything, sorted by generation in chronological order (newest first) with Intel listed above AMD when generations tie.

Game performance tabs (AOE2DE, AOE3DE, RA2YR)

Each tab adds an estimated relative-performance column; any combination can be open at once. The fastest CPU in that game is 100%. Values are a model (generation IPC × clock × a small thread bonus), not measured benchmarks.

Unlimited power / safe OC estimate

Assumes good air cooling, power limits removed, and the highest safe voltage. Unlocked parts (Intel K/KF/KS, AMD X/XT/non-X3D via PBO or manual multiplier) get extra clock; locked parts simply hold their turbo indefinitely. Max Turbo and TDP then show the stock value with the estimated value in italic gold beside it, and the game percentages are recalculated.

Fastest supported memory

Enables the fastest memory speed listed for each CPU's platform and recalculates the game estimates. Use the DDR4 / DDR5 buttons to choose the memory family for CPUs that support both; the selected speed is highlighted in the DDR Memory column. If a CPU does not support the selected family, its fastest supported family is used instead.

Search

Type any part of a model, generation, architecture or vendor. Separate several terms with commas to show them together, e.g. 6700k, 9500, 5800x.

Suffix filters

Untick a suffix (K, F, T, X, X3D, G …) to hide those models. “No suffix” covers plain models. Counts show how many models each suffix has.

Sorting

Click a column header to sort; click again to reverse. Shift-click adds secondary sort keys. Without a sort the table uses newest generation first, then tier and clock.

Column widths

Drag a header's right edge to resize. Double-click the edge to fit the widest cell exactly; double-click again to shrink to the narrowest. Columns fit their widest value automatically on load and whenever the data shown changes.

Highlighting rows

Click any row to give it a moving shimmer so it stands out; click it again to remove the highlight. Highlights survive sorting and filtering.

Generation banding

Consecutive rows of the same generation share a shade and a bright divider marks where a new generation starts.

Settings line

The grey line under the controls always describes the current settings (vendors, tabs, power mode, filters, sort, highlights).

Columns

Process Node in nm; Cores / Threads shows P- and E-cores with (HT)/(no HT) or SMT; IPC uplift is a generation-level estimate versus the vendor's previous generation; Year is the SKU's launch year; sticky Processor Model column and headers stay visible while scrolling.

Reset

Clears search, filters, sort, tabs, power mode, highlights and column widths.
